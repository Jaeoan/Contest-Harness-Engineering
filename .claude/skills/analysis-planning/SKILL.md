# 분석 계획 스킬

## 0단계: 문제 유형 판별 (가장 먼저)
문제의 **분석 단위**와 **결정이 어디에 걸려 있는지**로 유형을 정한다. 복수 가능, 주 유형 1개를 표시.
| 유형 | 판별 질문 | 예시 | 플레이북 |
|---|---|---|---|
| 공간 | 결정이 "어디에"인가? (설치 위치, 위험 구역) | 어린이보호구역 위험도(안양) | `spatial-risk-analysis` 스킬 |
| 개체(표형) | 결정이 "누구/어느 기관·가구"인가? | 복지 사각지대 가구, 위험 건물 | `references/problem-types.md` §개체 |
| 시계열 | 결정이 "언제/얼마나"인가? | 공공자전거 수요, 응급실 혼잡 | §시계열 |
| 텍스트 | 근거가 문서·민원·후기인가? | 반복 민원 원인, 정책 문의 | §텍스트 + `rag-for-public-policy` |
| 매칭/추천 | "이 사람에게 맞는 것"인가? | 청년 정책·지원금 추천 | §매칭 |
| 네트워크/흐름 | 연결·이동이 핵심인가? | 통학·통근 흐름, 배차 | §네트워크 |

**표현 방식도 같이 정한다** (화면의 주인공이 무엇인가): 지도 / 순위 리스트 / 차트·대시보드 / 개인 맞춤 결과 카드 / 검색·Q&A / 알림.
- 지도는 **사용자가 위치를 보고 행동을 바꿀 때만**. 위치 정보가 있다는 이유만으로 지도를 쓰지 않는다.
- 예: 복지 사각지대 → 담당 공무원용 "우선 방문 가구 순위 리스트"가 주인공, 지도는 보조이거나 없음.

## 핵심: 결정 → 질문 → 데이터 → 방법 (역순 금지)
1. **의사결정자와 결정**: "누가 / 무엇을 / 언제 바꾸는가"
2. **질문 레벨**: 서술(어디서 얼마나?) → 진단(왜 거기?) → 예측(다음엔 어디?) → 처방(어디부터?)
   공모전에서는 최소 **예측 또는 처방 1개**가 있어야 "분석"으로 인정받는다.
3. 질문별 방법 → `references/method-matrix.md` (유형별 상세는 `references/problem-types.md`)
4. 템플릿 → `references/plan-template.md`

## MVP 분석 (첫날 목표)
서술 1개 + 베이스라인 1개. 예) 공간: 격자별 과거 사고 합계 + "과거 순위 = 미래 순위" / 개체: 기존 선정 기준(규칙) 그대로 적용한 결과 / 시계열: 작년 같은 주 값.

## 흔한 함정
- 사고가 없던 곳을 "안전"으로 간주 → 노출량(교통량·인구)과 환경 특징으로 평가 대상을 확장
- 무작위 train/test 분할 → 시간·공간·개체 누수. 시간 분할, 공간 블록, 그룹(가구·기관) 분할 중 유형에 맞게.
- 좌표가 있다고 무조건 지도·격자로 가기 → 결정이 "어디에"가 아니면 공간 분석은 특징 몇 개(거리 등)로 충분하다.
- 시설 수(CCTV 등)를 "원인"으로 해석 → 유동인구 대리변수일 수 있음. 상관 표기.
- 행정구역 경계 밖 좌표, 타 지역 데이터 혼입 → 필터 전후 건수 기록.
- 모델만 있고 베이스라인 없음 → 개선폭을 말할 수 없음.
