# 질문 유형 → 방법 선택 매트릭스

| 질문 유형 | 1순위 방법 | 대안 | 검증 | 주의 |
|---|---|---|---|---|
| 어디에 몰려 있나 (핫스팟) | DBSCAN / HDBSCAN (좌표) | Getis-Ord Gi*, KDE | 공식 다발지역과 겹침률 | eps는 실제 거리(m) 투영좌표에서 |
| 다음엔 어디가 위험한가 (공간 예측) | 격자 + XGBoost/LightGBM | 포아송/음이항 회귀, GWR | 시간 분할, 공간 블록 CV, 베이스라인 대비 | 사고 0 격자 포함, 클래스 불균형 |
| 왜 거기인가 (요인) | SHAP (전역+지역) | 회귀 계수, 부분의존도 | 요인 방향이 상식/문헌과 일치? | 상관 표기 |
| 지역 간 격차 | 지니·타일 지수, 로렌츠 곡선 | 입지 계수 | 인구/수요 정규화 | 절대수 vs 1인당 |
| 접근성 (얼마나 멀리) | 네트워크 거리 (OSMnx/pgRouting) | 유클리드 거리(근사) | 샘플 경로 검증 | 직선거리 과소추정 |
| 어디에 먼저 설치 (최적화) | 최대 커버리지(MCLP), 탐욕 알고리즘 | p-median | 예산 시나리오별 커버율 | 후보지 제약 |
| 추세·계절성 | STL 분해, Prophet | ARIMA | 롤링 예측 오차 | 코로나 등 구조변화 |
| 정책 효과 (인과) | 이중차분(DiD) | 회귀불연속, 합성통제 | 평행추세 검정 | 데이터 기간 충분? |
| 민원·문서 텍스트 | 토픽모델(BERTopic) + RAG | 키워드 빈도, 분류기 | 샘플 수작업 라벨 대조 | 개인정보 마스킹 |
| 이상치 탐지 | Isolation Forest | z-score, IQR | 현장/뉴스 사례 대조 | 신규 시설 효과 |
| 대상 유형 나누기 (세그먼트) | K-means / 가우시안 혼합 (표준화 후) | 잠재계층분석(LCA), 계층적 군집 | 실루엣 점수 + 군집별 해석 가능성 | 군집 수는 해석 가능한 범위(3~6) |
| 집단 간 차이가 진짜인가 | t-검정 / Mann-Whitney, 카이제곱 | 회귀(통제변수 포함), 부트스트랩 신뢰구간 | 효과크기 함께 보고 | 표본 많으면 p값만으론 무의미 |
| 얼마나 걸리나 (처리·대기·생존 기간) | 카플란-마이어 + Cox 회귀 | 생존 GBM | 중도절단 처리 확인 | 미완료 건을 버리면 편향 |
| 수요 대비 공급 부족 (갭) | 수요 추정 − 공급량 지수, 수요/공급 비율 | 2단계 플로팅 캐치먼트(2SFCA) | 기존 공식 지표와 비교 | 수요 대리변수 근거 명시 |
| 여러 기준으로 우선순위 매기기 | 가중합 지수(AHP/엔트로피 가중) | TOPSIS | 가중치 민감도 분석 | 가중치 출처·근거 공개 |
| 이미지·영상 (위성·로드뷰·CCTV 이미지) | 사전학습 모델 특징 + 분류 | 객체 탐지(YOLO 계열) | 수작업 라벨 샘플 대조 | 라이선스·개인정보 |

## 위험도 지표 설계
- 건수 대신 **심각도 가중**: EPDO(사망·중상·경상·부상신고 가중치) 등. 가중치 출처를 명시.
- 노출 보정이 가능하면 "건수/노출량"(교통량, 인구)도 함께.
