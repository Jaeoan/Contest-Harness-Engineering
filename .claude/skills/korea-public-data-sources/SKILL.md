# 한국 공공데이터 소스 스킬

## 사용법
1. 문제 발굴 → `references/problem-sources.md`
2. 데이터 탐색 → `references/data-portals.md` (주제별 1순위 포털)
3. 찾은 모든 링크는 **WebFetch로 직접 열어** 데이터셋명·제공기관·최종갱신일을 확인한다. 이 목록의 URL도 바뀔 수 있다 — 열리지 않으면 검색으로 대체하고 harness-curator에게 알린다(`harness/proposals.md`).

## 검색 요령
- 공공데이터포털은 "지역명 + 대상 + 현황/표준데이터"로 검색 (예: `안양시 어린이보호구역`). 전국 **표준데이터**가 있으면 지역 필터로 쓰고 확장성 근거로 삼는다.
- 파일데이터 vs 오픈API: 1회성 분석은 파일, 서비스 실시간 갱신은 API.
- 좌표가 없으면 주소 → 좌표 변환 비용(지오코딩 API 한도)을 계획에 넣는다.
- 행정동 코드 체계(법정동 vs 행정동) 불일치 주의.

## 결합 키 우선순위
좌표(WGS84, EPSG:4326 / 한국 투영 EPSG:5179·5186) > 행정동 코드 > 도로명주소 > 기관명 텍스트
