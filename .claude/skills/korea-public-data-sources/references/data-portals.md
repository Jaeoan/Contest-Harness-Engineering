## 지자체 단독 데이터
시청 홈페이지 "정보공개/공공데이터" 메뉴 + 공공데이터포털에서 제공기관명 필터. 지역 공모전은 **지자체 단독 데이터를 모델 입력에 얼마나 썼는가**가 핵심 점수 요소다.
