# Well-known problem 발굴 소스

| 소스 | 무엇을 찾나 | 비고 |
|---|---|---|
| 국민권익위 민원 분석 / 국민신문고 https://www.epeople.go.kr | 반복 민원 키워드·지역 | 민원 빅데이터 보고서 |
| 감사원 감사보고서 https://www.bai.go.kr | 행정이 놓친 사각지대 | "관리 부실" 지적 사항 = 좋은 문제 |
| 국회입법조사처 https://www.nars.go.kr | 정책 쟁점·통계 정리 | 근거 수치가 잘 정리됨 |
| 통계청 사회조사 (KOSIS) | 시민 체감 불안·불편 | 주관 지표 |
| 뉴스 (BIGKinds https://www.bigkinds.or.kr, 포털 뉴스 검색, 지역 언론) | 반복 보도 추이, 대표 사례 | 방법은 `news-signal-scan` 스킬. 숫자는 원출처로 대체 |
| 지자체 주요업무계획·보도자료 | 지자체가 **이미 예산을 쓰는** 문제 | 지역 공모전에서 가장 설득력 높음 |
| 공공데이터포털 활용사례 / 역대 경진대회 수상작 | 이미 나온 아이디어 | 중복 회피 + 빈틈 찾기 |

## 좋은 문제 체크
- [ ] 수치로 규모를 말할 수 있다
- [ ] 위치·대상·시점을 데이터로 특정할 수 있다
- [ ] 결정권자(누가 예산/행동을 바꾸나)가 명확하다
- [ ] 예측 또는 우선순위화가 가능하다 (단순 지도 표시를 넘는다)
