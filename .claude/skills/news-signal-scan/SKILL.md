# 뉴스 신호 스캔

## 왜 뉴스를 보나
뉴스는 "이 문제가 사회적으로 인정된 문제인가"의 증거다. 단, **수치의 출처로는 쓰지 않는다** — 기사 속 숫자는 원출처(통계청·경찰청·기관 보도자료)를 찾아 그걸 인용한다.

## 절차
1. **키워드 확장 (10개 이상)**: 대상 × 현상 × 지역 조합. 예) 어린이보호구역·스쿨존 × 교통사고·불법주정차·보행 × 안양·경기. 행정 용어와 언론 용어를 둘 다 (예: "고립은둔청년" / "은둔형 외톨이").
2. **검색**:
   - WebSearch로 키워드별 검색, 연도 넣어 반복 ("스쿨존 사고 2024", "… 2025", "… 2026")
   - 빅카인즈(bigkinds.or.kr): 키워드 트렌드로 연도별 보도량 확인 (웹에서 사람이 확인하거나 사용자에게 스크린샷 요청)
   - 네이버 뉴스 API 키가 있으면 `scripts/naver_news.py`로 최신 기사 목록 수집
3. **추이 판정**: 최근 3년 연도별 대략 보도량 → ↑(증가) / →(지속) / ↓(감소). ↓이거나 한 해만 튀면 "일시적 이슈"로 표시.
4. **대표 기사 3건 선정**: 서로 다른 매체, 서로 다른 해. 제목·매체·날짜·링크·한 줄 요약(자기 말로). 본문 복사 금지.
5. **교차 확인**: 뉴스가 말하는 문제를 민원(국민신문고)·통계(KOSIS)·감사/국회 보고서 중 1개 이상에서 다시 확인. 뉴스에만 있고 공식 수치가 없으면 점수 감점.
6. **지역 신호**: 지역 공모전이면 지역 언론·시청 보도자료에서 해당 지자체가 이미 대응 중인지(예산, 조례, 사업) 확인 → "지자체가 돈 쓰는 문제"는 설득력이 높다.

## 출력 (후보 카드의 "뉴스 신호" 칸에 그대로)
`추이: → (2024 약 N건, 2025 약 N건, 2026 약 N건 / 출처: 빅카인즈 또는 검색 결과 기준)`
`대표: ① 매체, 2025.03.12, "제목", 링크 — 요약 ...`
건수를 정확히 못 세면 "약"과 기준을 명시한다. 추정을 사실처럼 쓰지 않는다.
