# 공공데이터 공모전 일반 심사기준 ↔ 섹션 매핑
※ 대회마다 다르다. 요강의 실제 기준표로 이 표를 먼저 교체할 것.

| 흔한 심사항목 | 심사위원이 찾는 것 | 대응 섹션 | 강하게 만드는 방법 |
|---|---|---|---|
| 공공데이터 활용 적정성 | 이 데이터가 꼭 필요한가, 여러 데이터를 결합했나 | 2 | 데이터별 "대체 불가 이유", 결합 키, 모델 입력 중 공공데이터 비중 |
| 창의성·차별성 | 기존 서비스와 뭐가 다른가 | 1-3, 4 | 기존 해법 표 + 빈틈 한 문장 |
| 기술 완성도 | 실제로 동작하나, 분석이 타당한가 | 3, 4-2 | 검증 지표, 베이스라인 비교, 실제 화면 |
| 사업성·실현가능성 | 누가 쓰고 누가 유지하나 | 4-1, 5 | 결정 순간, 갱신 주기, 운영 비용 |
| 공익성·파급효과 | 누가 얼마나 혜택 보나 | 5 | 대상 인원·구역 수, 타 지역 확장 |
