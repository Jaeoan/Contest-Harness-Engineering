# 공간 위험도 분석 플레이북

기준 사례: `examples/anyang-case.md` (250m 격자 819칸, 특징 10종, DBSCAN 위험구역, XGBoost + 요인 기여도).

## 1. 좌표계
- 거리 계산은 반드시 미터 단위 투영좌표: **EPSG:5179**(UTM-K) 또는 5186. 저장·API 전달은 EPSG:4326.
- 입력 좌표의 원래 좌표계를 확인 (위경도 뒤바뀜, TM 좌표 혼재 흔함).

## 2. 분석 단위: 격자
- 크기 근거를 적는다: 보행 생활권(250m ≈ 도보 3분), 데이터 밀도(격자당 평균 사건 수), 행정 활용성.
- 행정경계로 클리핑 → 경계 밖 사건은 제외하고 **건수를 기록**.
- 대안: H3 해상도 8~9 (육각, 인접성 균일). 격자는 행정 보고가 쉽다.
- 스크립트: `scripts/grid_features.py` (격자 생성 + 최근접 거리 + 반경 내 개수)

## 3. 타깃(위험도)
- 심각도 가중(EPDO 등), 가중치와 출처를 리포트에 명시.
- 예측 타깃은 **미래 기간**: 예) 2019–2022 특징 → 2023 EPDO. 같은 기간 사건 건수를 특징에 넣으면 누수.

## 4. 특징 설계 (그룹별로 기록)
| 그룹 | 예시 | 비고 |
|---|---|---|
| 과거 이력 | 과거 사건 수, 과거 EPDO, 반경 300m 과거 교차로 사고 | 타깃 기간과 분리 |
| 시설 | 최근접 CCTV 거리, 200/500m 내 CCTV 수 | 유동인구 대리일 수 있음 |
| 제도 | 보호구역 포함 여부, 최근접 보호구역 거리 | |
| 환경 | 도로 폭·교차로 수·학교 수 | 가능하면 |
| 노출 | 인구·유동인구 | 있으면 정규화에 사용 |

## 5. 핫스팟
- DBSCAN: 투영좌표, `eps`(m)와 `min_samples` 선택 근거(k-distance 그래프) 기록. 군집별 EPDO 합으로 등급.
- 외부 검증: 공식 사고다발지역 좌표가 군집 내에 포함되는 비율(겹침률)을 보고.

## 6. 모델
1. 베이스라인: 과거 EPDO 순위 그대로 미래 예측 → Spearman, Top-k 적중률.
2. XGBoost/LightGBM (회귀 또는 위험등급 분류). 불균형이면 가중치 또는 Tweedie/Poisson 목적함수.
3. 검증: 시간 분할 + 공간 블록 CV(블록 1km 이상). 무작위 분할 금지.
4. 보고: 베이스라인 대비 개선폭 먼저, 절대 지표 나중.

## 7. 해석
- SHAP 전역 기여도(그룹 합산도 제시), 격자별 Top3 요인: `"과거 사고 19건(+), 교차로 사고 13건(+), 보호구역 밖 675m(−)"` 형식.
- 모든 요인 설명에 "상관" 표기. 시설 밀도는 활동량 대리변수 가능성 명시.

## 8. 내보내기 (백엔드용)
`data/export/grid_risk.parquet`: grid_id, geometry(WKT, 4326), risk_score, risk_grade, top_factors(JSON), model_version, computed_at
`data/export/risk_zones.parquet`: zone_id, geometry, grade, epdo_sum, n_events
스키마를 `data/export/SCHEMA.md`에 기록.
