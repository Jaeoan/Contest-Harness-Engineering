# 기준 사례: 안양시 어린이보호구역 교통안전 위험도 (2026 안양시 공공데이터·AI 활용 대학생 경진대회)

> 새 프로젝트의 "이 수준 이상" 기준. 수치는 당시 산출물 기준이며 재사용 시 재계산할 것.

## 문제
어린이보호구역 안전 개선의 지역 불균형 — 사고가 난 곳만 보면 지도의 절반이 빈칸이다.

## 분석
- 단위: 250m 격자 819칸 (사고 이력 없던 370칸도 평가 대상)
- 위험도: EPDO 가중 · 핫스팟: DBSCAN 위험구역 · 예측: XGBoost
- 특징(v4): cctv_dist, cctv_200m, cctv_500m, zone_dist, zone_300m, in_zone, zone_cctv, inter_hist_300m, n_hist, epdo_hist
- 해석: CCTV 관련 3변수 기여도 합 0.343 → "상관, 참고 정보"로 표기. 격자별 요인 예: "과거 사고 19건(+), 교차로 사고 13건(+), 보호구역 밖 675m(−)"
- 검증: 군집 결과와 공식 사고다발지역 교차검증 81%

## 기획서에서 효과가 컸던 문장 패턴

- "설문으로는 '위험해 보이는 곳'을 안다. '실제로 다친 곳'은 알 수 없다."

- "따로 있을 때는 각자 목록이었습니다. 겹치자 위험 지도가 됐습니다."

## 교훈 (하네스 규칙으로 승격됨)
1. 링크를 검색으로 확인하지 않고 문서에 썼다 → 나중에 재조사. ⇒ data-scout "직접 열어 확인" 규칙
2. 이전 프로젝트(대전) CCTV 812건이 파일에 섞여 있었다 → ⇒ 지역 필터 전후 건수 기록 규칙
3. 안전비상벨 데이터가 모델에 들어갔는지 불명확 → ⇒ 사용/검토/미사용 구분, 특징표=데이터표 대조
4. 문서마다 모델 입력 수가 9종/10종으로 달랐다 → ⇒ reality-checker 수치 대조표 검사
